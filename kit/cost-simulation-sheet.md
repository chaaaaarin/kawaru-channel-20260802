# 🎁 コスト削減シミュレーションシート

現在Sol・Terra（またはGPT-5.6以外の上位モデル）に任せているタスクのうち、Lunaに移せるものを見積もり、削減額を試算するためのチェックシートです。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: そのままテキストとして手元に置き、□を埋めながら進めてください。指示例はそのままAIのチャット欄に貼り付けて使えます。

```text
【Lunaコスト削減シミュレーションシート】

■ ステップ1：現状のAI利用コストを洗い出す
□ 直近1ヶ月のAPI利用料金の合計はいくらか
→ YES: 明細から合計金額を記録する
指示例: 直近1ヶ月のAPI利用明細を確認し、モデル別（Sol/Terra/Luna等）の合計金額と割合を表にまとめてください。

□ その中で、Sol・Terraに任せているタスクの内訳が分かるか
→ YES: タスクの種類（コーディング/文書作成/分析等）ごとに集計する
指示例: 直近1ヶ月のAPIリクエストログから、タスクの種類ごとの呼び出し回数とトークン消費量を集計してください。

■ ステップ2：Lunaに移せるタスクを判定する
□ 仕様・要件が事前に明確に決まっているタスクか
→ YES: Luna移行の第一候補
□ 長い会話履歴や大量資料を一度に読ませる必要があるか
→ YES: Lunaは長文脈理解が弱いため、当面はTerra/Solのまま残す
□ 曖昧な判断・企画立案を求めるタスクか
→ YES: Lunaでは力不足の可能性が高い。Solのまま残す
指示例: このタスク一覧を確認し、それぞれ「仕様が明確か」「長い文脈が必要か」「曖昧な判断が要るか」の3点で分類し、Luna移行に向くタスクだけを抜き出してください。

■ ステップ3：移行候補タスクの削減額を試算する
□ 移行候補タスクの現在の月間コストが分かるか
→ YES: そのコストを基準値とする
□ Lunaの価格（入力$0.20/出力$1.20 ・ 100万トークンあたり）で同じ処理量を再計算したか
→ YES: 差額が削減見込み額になる
指示例: 移行候補タスクの月間トークン消費量をもとに、現在のモデル価格とLunaの価格（入力$0.20/出力$1.20、100万トークンあたり）でそれぞれ月額コストを計算し、差額と削減率を表で示してください。

■ ステップ4：推論設定によるコスト増を織り込む
□ Luna移行後、reasoning effort（推論設定）をHigh/Maxに上げる必要があるタスクか
→ YES: High/Max設定は同じLunaでもトークン消費が増えるため、その分を上乗せして再試算する
指示例: このタスクをLuna Highで実行した場合の想定トークン消費量を、Low設定時と比較して見積もってください。差が大きい場合はその理由も添えてください。

■ ステップ5：段階的に移行し、実測値で見直す
□ まず1つのタスク種別だけを1週間Lunaに任せてみたか
→ YES: 実際のコスト・品質を記録し、試算値と比較する
□ 品質が想定より落ちる場面が出たか
→ YES: そのタスクだけTerra/Solに戻し、それ以外の移行を継続する
指示例: 今週Lunaに任せたタスクの実際のコストと成果物の品質を、事前の試算値と比較して差分を報告してください。

※ 本シートの試算はあくまで見積もりです。実際の削減額は利用状況・推論設定・タスクの複雑さにより変動します。断定的な削減保証はできません。
```

**ポイント**: いきなり全タスクを移行せず、まず1種類のタスクで実測してから範囲を広げると、品質低下のリスクを抑えながら削減効果を確認できます。
